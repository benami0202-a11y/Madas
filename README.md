# מערך הכושר הפלוגתי

מערכת ניהול הכושר של קורס הקצינים - אפליקציית React מלאה (SPA, RTL, מובייל+דסקטופ) לניהול נוכחות, רמות כושר, מבחני כושר, תוכנית אימונים, משימות סופ"ש, ניקוד ודוחות.

## טכנולוגיות

- React + TypeScript + Vite
- Tailwind CSS v4
- Framer Motion, Recharts
- React Router
- שכבת נתונים מקומית (localStorage) בממשק שמאפשר מעבר עתידי ל-Firebase/Supabase ללא שינוי בקומפוננטות (ראו `src/lib/db/repository.ts`)

## הרצה

```bash
npm install
npm run dev
```

## בנייה לפרודקשן

```bash
npm run build
```

נתוני הדגמה (40 חניכים, נוכחות, מבחני כושר, תוכנית אימונים, משימות סופ"ש וניקוד) נטענים אוטומטית בהפעלה ראשונה ונשמרים ב-localStorage. ניתן לאפס לנתוני הדגמה מחדש במסך ההגדרות.
